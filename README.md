# RC-Tool（G7 Pro 8K / 天王星8K 摇杆 RC 滤波调节工具）

直连 USB HID 的独立小工具：调节 GameSir **G7 Pro 8K（天王星8K / G7ProCE）** 左右摇杆的
RC 滤波（antiJitter：增抖 / 防抖）参数、管理 GameSir Connect 的「RC 强制归零」补丁，
并可通过官方升级通道直接刷写固件。纯原生 C# WinForms 单文件 exe，无需安装、
无需 Python、无需浏览器，运行时零落盘文件。

## 功能

- **4 个配置档 = 4 个 Tab**：连接后自动读取全部档位、显示真实档名、自动高亮当前档；
  点 Tab 即把手柄当前档切换过去。
- **左右摇杆独立调节**：滑块 −10…+10（负=增抖 / 0=关闭 / 正=防抖），数值跟随滑块显示；
  应用后自动回读校验。档内字节 49（左）/ 50（右），字节值 = clamp(1..21, 值+11)。
- **全自动连接**：后台每 3 秒检测手柄，插拔自动连接/重连/断联复位，无需任何"识别"按钮。
- **固件刷写**（与官方 App 同一通道，不改任何 App 文件）：
  - 内置官方 V2.10 / V2.38 两套固件，可随时一键恢复；
  - 下拉选「选择固件文件…」会立即弹出文件选择框，选中后文件名显示在固件选择栏里，
    再点「刷写固件…」才开始刷写（支持任意 .ufw）。
- **固件指示灯**：顶栏显示手柄上报的固件版本——0938（RC 定制固件）或 0210（官方 V2.10，
  RC 原生可用）为绿色，其余官方版本（0219 / 0238 等）为橙色（RC 无效），未连接灰色。
- **补丁**：去除 GameSir Connect 对 RC 值的强制归零（等长改写 app.asar，可一键恢复，
  自动备份 app.asar.rctool.bak）；附「重启 GameSir Connect」「选择安装路径…」。
- **中英文切换**：型号右侧胶囊一键切换。
- 配色与官方 GameSir Connect 一致（近黑渐变 + GameSir 橙红）；标题为内嵌 ROG 品牌字标。

## 使用

1. USB 连接手柄（有线即可；开着 GameSir Connect 设备页时建议先退出它）；
2. 双击 `RC-Tool.exe`，等右上「手柄: G7P8K」；
3. 选 Tab → 拖滑块 → 「应用到左/右摇杆」；
4. 补丁：完全退出 GameSir Connect（含托盘）→「去除RC强制归零」→ 重启 App 生效；
5. 刷固件：下拉选固件（或「选择固件文件…」选任意 .ufw）→「刷写固件…」；
   刷写约 30–90 秒，完成后手柄自动重启。失败可直接重试。

## 固件刷写原理（与官方 App 完全一致）

1. HID 配置接口发送 `[15,23,85,136]`（快速升级命令），手柄枚举成 U 盘升级模式；
2. 调用官方 `jl_firmware_upgrade_x86.dll`：
   `JL_loadUfwData → JL_getUfwPidVid → JL_queryDevicePidVid → JL_setDualBackupBurning(1) → JL_upgradeDevice`，
   双 bank 同时烧写并逐块校验，完成后自动重启；
3. 升级库已内嵌在 exe 中（运行时释放到 `%TEMP%\RCTool\dfu\`），刷写不需要安装
   GameSir Connect；「安装路径」仅用于给 App 打 antiJitter 补丁。

## 直连 HID 协议（真机实测校准）

- 发送报告 ID `0x0F`，64 字节；设备应答报告 ID `0x10`（手柄状态流为 `0x12`，忽略）。
- 进入配置模式 `[15,1]` → 回 `10-06` Ack（会话内一次）。
- 读档块 `[15,4,档,Hi,Lo,Len]` → `10-05-档-Hi-Lo-Len-data`；
  写档 `[15,3,档,Hi,Lo,Len,data]`；切档 `[15,7,档]`；
  当前档 `[15,11]` → `10-0C-档号`；固件版本 `[15,9]` → `10-0A`（UTF-16LE）。
- 档总长 1070 字节；档名 = 0..31；RC 值 = 字节 49(左) / 50(右)。
- 传输层为 **Overlapped I/O + 全超时 + 500ms 心跳**，设备异常不会卡死界面。

## 构建

Windows 上双击 `build.cmd`（需要 .NET Framework 4.x 自带 csc.exe）。
本工具为 **32 位程序**（官方升级库为 x86）。不放入上述可选资源时，除内置固件外的
功能（读档/写档/选文件刷写/补丁）全部可用。
