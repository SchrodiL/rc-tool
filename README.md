# RC-Tool

中文 | [English](README_EN.md)

GameSir 天王星8K / G7 Pro 8K 摇杆 RC 滤波调节工具。
*Stick RC-filter tuner for GameSir Uranus 8K (G7 Pro 8K), via direct USB HID.*

单文件 Windows 小工具，纯 C# WinForms，无需安装、无需第三方运行时
（.NET Framework 4.x 系统自带即可构建）。

## 功能

- 直连 USB HID，不依赖 GameSir Connect 运行
- 4 个配置档四个 Tab：自动读取档名与数值，点 Tab 即切换手柄当前档
- 左右摇杆独立调节，滑块 −10 ~ +10（负=增抖，0=关闭，正=防抖），写入后自动回读校验
- 自动检测插拔与重连，断线恢复后自动重读
- 一键去除 GameSir Connect 对 RC 值的强制归零（等长改写 app.asar，可一键恢复并自动备份）
- 中英文界面切换、官方同款深色配色

## 支持型号

- **GameSir 天王星8K / G7 Pro 8K**（G7ProCE，含全部配色与联名版）
- 其他型号的摇杆配置结构不同或未公开固件，暂不支持

## 构建

双击 `build.cmd`。使用系统自带的 `csc.exe`（.NET Framework 4.x）编译，
产物为约 120 KB 的单文件 `RC-Tool.exe`，编译成功后自动启动。

## 使用

1. USB 连接手柄（建议先完全退出 GameSir Connect）
2. 运行 `RC-Tool.exe`，等待右上角显示"手柄: G7P8K"
3. 选 Tab → 拖动滑块 → "应用到左/右摇杆"
4. 补丁：完全退出 GameSir Connect（含托盘）→ "去除RC强制归零" → 重启 App 生效

## 使用说明

### 连接手柄

用 USB 线连接手柄即可（有线模式或 2.4G 模式都可以），不需要打开 GameSir Connect。
工具每 3 秒自动检测一次，插上自动连接、拔掉自动断开、重新插上自动重连，无需手动操作。

### 调节 RC

1. 顶部"手柄"指示器显示 **手柄: G7P8K** 即连接成功；
2. 点击某个 Tab 选择要调的配置档（点 Tab 的同时手柄会切换到该档）；
3. 拖动滑块：左边是增抖方向（−10），右边是防抖方向（+10），滑块上方会实时显示当前数值；
4. 调好后点"**应用到左摇杆 / 应用到右摇杆**"——工具会把数值写入手柄并自动回读校验，
   成功后会提示；失败会显示具体原因；
5. 打开游戏感受效果，不满意继续微调再应用。

数值含义：`-10 ~ -1` 增抖（越大越抖）；`0` 关闭；`1 ~ 10` 防抖（越大越平滑）。
左右摇杆可以独立设置。建议防抖先试 2~3，不够再加；增抖属于部分赛事禁用设置，注意规则。

### 补丁（去除 RC 强制归零）

GameSir Connect 每次打开都会把 RC 值强制归零。本工具可以去掉这个逻辑：

1. **完全退出 GameSir Connect**（包括右下角托盘图标）；
2. 点"**去除RC强制归零**"，等待进度走完（读取→扫描→写入，几秒钟）；
3. 重新打开 GameSir Connect，此时它不会再覆盖你设置的 RC 值；
4. 想还原时点"**恢复官方原版**"即可（首次打补丁前会自动备份）。

如果提示找不到 App 路径，点"**选择安装路径…**"手动指定 GameSir Connect 的安装目录。

### 其他

- 语言切换：型号右侧的小胶囊，显示 EN 时点一下切英文，显示"中文"时切回中文；
- 设置保存在手柄的配置档里，断电不丢失，换电脑接同一条手柄依然有效；
- 想恢复某档默认设置：把滑块拖回 0 再应用即可。
